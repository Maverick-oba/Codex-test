# SBI PDF Rename

年1回程度、SBI証券からダウンロードしたPDFのファイル名を整理するためのメモです。

## 目的

ダウンロード時にUUIDのような分かりにくい名前になっているPDFを、本文から発行日と書類タイトルを読み取り、次の形式へ整理します。

```
YYYY-MM-DD_書類タイトル.pdf
```

例:

```
2026-04-03_取引残高報告書.pdf
2026-07-13_株価指数オプション取引報告書.pdf
2026-07-27_株価指数先物取引報告書.pdf
```

## 安全な手順

1. 対象フォルダー内のPDFをすべて確認する。
2. まずはリネームせず、元ファイル名・推奨ファイル名・発行日・タイトル・判定根拠・状態をCSVへ出力する。
3. 発行日不明、タイトル不明、同名候補は「要確認」として止める。
4. 要確認PDFは本文の全ページを再確認する。
5. 同名候補は内容、取引日、商品、限月、ページ数、SHA256などを比較する。
6. 全件確認後に一括リネームする。
7. 上書きは禁止する。
8. リネーム前後でSHA256が一致することを確認する。
9. 最後にPDF件数、未整理ファイル、命名形式外ファイルがないことを確認する。

## 命名ルール

- 証券会社名は付けない。
- 発行日はPDF本文の記載を優先する。
- タイトルは意味を変えない範囲で短く整理する。
- ファイルの作成日時・更新日時は発行日の代用にしない。
- 同名になる場合は内容を比較して、必要なら最小限の識別情報を付ける。
- PDF本文自体は変更しない。

## 2026-10-04 実績

対象73件を整理。

- 成功: 73件
- UUID形式のPDF: 0件
- 命名形式外のPDF: 0件
- リネーム前後のSHA256: 全件一致
