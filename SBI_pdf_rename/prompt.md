# Codex Prompt

対象フォルダー:

```
C:\Users\oba44\Downloads\SBI
```

このフォルダー内のすべてのPDFを確認し、本文から「発行日」と「書類タイトル」を抽出してください。

命名形式:

```
YYYY-MM-DD_書類タイトル.pdf
```

ルール:

- 証券会社名は付けない
- 書類タイトルは意味を変えない範囲で短く整理する
- 発行日はPDF本文の記載を優先する
- ファイルの作成日時や更新日時は発行日の代用にしない
- 発行日を特定できないPDFはリネームしない
- タイトル判定に自信がないPDFもリネームしない
- 同名ファイルになる場合は上書きしない
- スキャンPDFなど本文を直接読めないものは「要確認」にする
- PDF本文自体は変更しない

最初の実行では絶対にファイル名を変更しないでください。

まず以下の一覧をCSVに出力してください。

- 元ファイル名
- 推奨ファイル名
- 発行日
- 判定した書類タイトル
- 判定根拠
- 状態（OK / 要確認）

要確認のPDFは、本文全ページを再調査してください。

同名候補がある場合は、各PDFについて次を比較してください。

- PDFタイトル
- 発行日
- 取引日
- 対象商品
- 限月や銘柄
- ページ数
- SHA256

別書類であれば、既存の命名ルールを崩さず区別できる名前を提案してください。完全重複の可能性がある場合も勝手に削除しないでください。

全件の候補確認後、ユーザーの了承を得てから一括リネームしてください。

リネーム時:

- 上書き禁止
- 想定外の同名ファイルが存在した場合は、そのファイルだけ処理を止めて報告
- リネーム前後でSHA256を比較
- 最後にPDF件数、UUID形式の残存件数、命名形式外件数を確認
- 元ファイル名 → 新ファイル名の実行結果一覧を出力
